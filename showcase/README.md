# PinkInk Theme Showcase

This workspace exercises the workbench and syntax colors in **PinkInk Dark** and **PinkInk Light**.

> Pink is the primary voice, while cyan and magenta add bright complementary accents.

## Syntax coverage

- **TypeScript and C#** show semantic highlighting for types, interfaces, properties, methods, parameters, enums, and constants.
- **Python, Go, and Rust** add decorators, attributes, language keywords, format strings, and error-handling constructs.
- **Java, C++, and Swift** contrast primitive types, records/structs, enums, interfaces/protocols, type aliases, annotations, and members.
- **Ruby, PHP, and Shell** exercise symbols, instance variables, traits/enums, namespaces, special methods, and positional parameters.
- **HTML, CSS, and SCSS** cover tags, attributes, selectors, properties, custom properties, variables, map keys, and color values.
- **JSON and YAML** make object keys, strings, numbers, booleans, and null values easy to compare.
- **PowerShell and SQL** exercise shell variables, commands, functions, clauses, and operators.

## Markdown treatment

Normal text stays calm. **Bold text has weight**, while *emphasized text changes color without becoming italic*. Links such as [Visual Studio Code](https://code.visualstudio.com/) use the cyan accent, and `inline code` uses the warm string color.
